# Postman API Collection

This directory contains the Postman API collection for testing all endpoints in the Employee Request Management System.

## Contents
- `Employee-Management.postman_collection.json` (will be generated upon backend completion)

## Folders in Collection:
1. `Authentication` - Login, Logout, Me
2. `Admin` - Employees CRUD, Manager assignment, Activity logs, Dashboard
3. `Manager` - Team members, Team requests, Dashboard
4. `Employee` - Submit requests, My requests, Dashboard
5. `Approvals & Comments` - Approve, Reject, Comments
6. `Notifications` - List notifications, Mark read, Mark all read
